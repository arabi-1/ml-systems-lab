# Data

Raw datasets are not committed. Download them manually and place them in `data/raw/`.

## Task 1: Titanic

- Source: https://www.kaggle.com/c/titanic/data (free Kaggle account required)
- File needed: `train.csv`
- Location: `labs/lab04_decision_trees/data/raw/train.csv`
- `test.csv` is not used because it has no survival labels. The model is evaluated on a held-out split of `train.csv`.

## Task 2: Car Evaluation

- Source: https://archive.ics.uci.edu/dataset/19/car+evaluation
- File needed: `car.data`
- Location: `labs/lab04_decision_trees/data/raw/car.data`
- Columns (no header row in the file): buying, maint, doors, persons, lug_boot, safety, class
